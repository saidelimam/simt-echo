## Findings

### W3-06 — Pipeline assembly + live check (BLOCK)

- **B1 (BLOCK)** The live 60 m check was never run: measurements.md
  records the blocker honestly but no latency/cost/job exists, while
  the commit title claims the check. (Live attempt now in R5.)
- **B2 (BLOCK)** `samFrames` is neither the spec'd vendor sum
  (`usage.video_frames_processed` in `response.completed` — discarded
  by the SSE collector) nor an accurate send count: the proxy counts
  one clip per checkpoint while ground sends once per *candidate*
  (≤2× undercount), and counts checkpoints that never sent video.
- **M1 (MAJOR)** Assemble trusts ground's rank instead of computing
  §6.6 rank; defensible (ground computes it) but the deviation is
  silent and the test enshrines trust-not-recompute. Recorded as a
  plan amendment in the tracker: ground computes, assemble sorts.
- **M2 (MAJOR)** `samMs` is whole ground-step wall time, populated even
  when SAM never ran — misleading as a cost signal.
- **M3 (MAJOR)** Ground failure errors the whole job with no degraded
  result test; assemble drops manifest checkpoints missing from ground.
- Verified good: scout+ground output now reaches the public result
  (the review-0001 discard is fixed), per-checkpoint deterministic
  sort, box-only usage omission, measurements fabricate nothing.

### W3-09 — Muse Spark scout provider (BLOCK)

- **B1 (BLOCK)** This branch predates the `meta.ts` done-event fix
  (648e722): Spark output arrives done-only live, reads as empty, and
  Spark can never return candidates. Its SSE test double invents
  delta events — the same invented shape that hid the SAM bug.
- **M1 (MAJOR)** Spark cleaning uses a job-global image set: a
  candidate for checkpoint A may name checkpoint B's keyframe —
  breaking review 0001's per-checkpoint loaded-image invariant.
- **M2 (MAJOR)** Retryable Meta 429/5xx are wrapped into typed
  `all_models_failed` (→ NonRetryable at the Workflow), so transient
  errors permanently fail or silently switch providers.
- Verified good: request shape/model id/SYSTEM reuse, strict schema,
  closed typed failures, key gating + SCOUT_ORDER fall-through, no
  workers-ai regression (158713d intact), secrets header-only.

### W3-07 — Merge candidates into Review (BLOCK)

- **B1 (BLOCK)** Box scaling conflates grids: `candidateCropBox`
  treats SAM pixel boxes as 0–1000-grid (`kf/frame` cancels → always
  `box/1000`). SAM box [300,300,420,1100] on 720×1280 yields
  [0.30,0.30,0.42,1.0] instead of [0.417,0.234,0.583,0.859] — grounded
  crops and overlays are wrong, and the test asserts the wrong math.
- **B2 (BLOCK)** `privacyRisk` candidates are preselected (rank-only
  sort, index 0) and the flag is destroyed on Use (Landmark has no
  such field) — prior reviews flagged exactly this for W3-07/W3-08.
- **M1 (MAJOR)** `candidate.keyframeId` ignored: overlay/crop always
  use the hero frame, though the box may belong to another keyframe.
- **M2 (MAJOR)** Mask scaling uses integer division (`bitmap.width /
  maskW` truncates), displacing masks.
- **M3 (MAJOR)** EOF-truncated mask SVG throws IndexOutOfBounds in
  composition instead of degrading to box-only.
- Verified good: candidate source is the real W3-02/W3-06 contract
  (job record → `api.get().resultRaw`), geometry never mutated
  (side map; legs/path asserted untouched), CREATOR_VERIFIED only on
  explicit Use, unreviewed suggestions unexportable, provenance set.

### W5-02 — Camera overlay (BLOCK as Complete; completes here as HUD + mask-over-crop)
